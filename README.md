# FreshBasket Grocery App (Demo)

This is a Flutter demo project with Shop, Cart, Rewards and Prime screens.

## Build APK automatically with GitHub Actions
1. Upload the contents of this project to the root of your GitHub repository.
2. Make sure the workflow file is at `.github/workflows/android-apk.yml`.
3. Open the repository's **Actions** tab.
4. Select **Build FreshBasket Android APK** and run it, or push a commit to `main`.
5. When the run completes, open the run and download the `freshbasket-android-apk` artifact.

## Important
- Reward button is a simulation only; it does not show a real ad.
- Checkout is not connected to payments or a backend.
- No user login, live inventory, delivery tracking, or server verification is included.
- This is a prototype, not a production grocery service.
